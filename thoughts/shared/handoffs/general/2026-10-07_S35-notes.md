## Design

Modelled on the EDIT route: router verdict → `Route` → `Pipeline::dispatch` arm → a `note()` method,
with the same deny-by-default route gate, commit point and `Notice`s.

* **Route** `Route::Note` (`"note"`, additive open-enum value) in `dictate-proto`; `RouteType::Note`
  in `router.rs`. Triggers: `note:` / `note,` (also unspaced), and the phrases `note to self`,
  `quick note`, `new note`, `take a note`, `make a note`, `add a note`, matched as whole words,
  case-insensitive, punctuation after the last word allowed. A bare "note" is **deliberately not** a
  trigger (see Deviations). The body is the text after the trigger. Priority: after the edit
  triggers, before `timer`/`local`. Callers may force the route with `SessionOptions.route`
  (then a leading trigger is still stripped, as EDIT does).
* **Dispatch** (`pipeline.rs::note`): nothing is typed; `stages.timings.inject = skipped
  (route_not_eligible)` and the outcome is `InjectionOutcome::Skipped{route_not_eligible}`, so the
  `Transcript` carries `route:"note"` and the saved text. The write takes `token.enter_commit()`
  first: a cancelled session stores nothing and a late cancel is answered `TooLate`.
  Refusals (never typed instead): session `privacy`, global privacy, history disabled → `Skipped
  {not_permitted}` + a desktop error notice; an empty body (`"note:"`) → `Skipped{no_speech_detected}`;
  a poisoned/failed store → `Skipped{dependency_unavailable}`. `Notice::NoteSaved(text)` is new.
* **Store** (`dictate-history/src/notes.rs`): `HistoryStore::{add_note, list_notes, delete_note,
  note_count}` on the existing connection. `add_note` returns `NoteError::{Private,Disabled,Empty,Storage}`.
  Search is `LIKE '%q%' ESCAPE '\'` (ASCII case-insensitive, `%`/`_`/`\` literal), no FTS: notes are
  small, and an FTS shadow table would be one more copy of the text to scrub and one more thing in the
  migration. Limit default 100, cap 500. `apply_retention` now also expires notes.
* **Protocol**: `list_notes{query?,limit?,id?}` → `notes{notes:[Note]}`; `delete_note{id}` → `deleted`
  (or `not_found`). `Note{id, ts_ms, text, word_count}`. Gated by the **existing** `history_read` /
  `history_write` features (notes are history-class data), so no new `Features` flag and no change to
  the capability sets, golden-pinned in `tests/golden.rs`. `server.rs` has the two arms.
* **CLI** `dictate notes [list|search Q|show N|copy N|rm N|new]`, `dictate start --route note`.
  `copy` pipes to `wl-copy`/`xclip`/`xsel` (the CLI links no clipboard crate; its dependency tree is
  unchanged). Rows are defused with `safe::`/`truncate`; timestamps are UTC `YYYY-MM-DD HH:MM`.
* **UI** hub **Notes** page (search, copy, two-step delete, *Dictate a note* / *Stop and save*, privacy
  badge), `list_notes`/`delete_note` Tauri commands (`start_dictation`/`stop` already existed),
  `--hub notes`. Pure model in `ui/src/lib/notes.ts`.
* **Docs**: `docs/notes.md`, `docs/protocol.md` ("Scratchpad (S35)", command table, route list),
  `AGENTS.md`, `ui/README.md`.

## Migration (needs the manager's one pre-merge review)

`sql/schema.sql` is executed on every open (every statement `IF NOT EXISTS`), then `migrate()` stamps
`schema_version`. `SCHEMA_VERSION` 2 → 3. The SQL added, verbatim:

```sql
CREATE TABLE IF NOT EXISTS notes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    created_at_ms INTEGER NOT NULL,
    text TEXT NOT NULL,
    word_count INTEGER NOT NULL DEFAULT 0
);

CREATE INDEX IF NOT EXISTS notes_created_at_ms ON notes (created_at_ms);
```

Purely additive: `interactions`, its FTS table and triggers are untouched, so no dictation row can be
lost; re-running is a no-op; an older `dictated` opening the newer DB just re-stamps version 2 and
ignores the table. `created_at_ms` is epoch milliseconds (retention compares against it);
`AUTOINCREMENT` so a deleted note's id is never reused. Tests
(`crates/dictate-history/tests/notes.rs`): `migration_adds_the_notes_table_and_keeps_every_dictation`
(a real v2-shaped DB: `notes` dropped, `schema_version=2`, a populated `interactions` row → reopen →
row intact, table present and writable, `schema_version==3`, a second reopen keeps the note).

## Deviations from the spec / things the integrator must know

1. **"note …" is not a bare-word trigger.** The spec says route `"note …"`. A bare first word would take
   "note that the deadline moved" away from the window the user is typing into. Triggers are `note:`,
   `note,` and the unambiguous phrases above; everything else still types (pinned by
   `a_bare_note_word_and_lookalikes_stay_typed` and the daemon test
   `ordinary_prose_that_mentions_note_is_still_typed`). `dictate notes new` / `start --route note` /
   the UI button cover the case where Whisper mishears the trigger.
2. **History-table flavor chosen** (spec: markdown file or history table). A file would sit outside
   privacy mode and retention, which the Issue requires.
3. **Retention expires notes; `purge_history` does not delete them.** Retention is the user's declared
   window and applies; the explicit purge is documented as dictations-only because notes are explicit
   saves, deleted with `delete_note` / `dictate notes rm`. Easy to flip if Jake wants a purge to take
   notes too (one `DELETE FROM notes` in `purge`).
4. **The note text is also in the dictation's `interactions` row** (every route's transcript is). It is
   subject to the same privacy/retention there; a note saved in privacy mode is in neither.
5. **No LLM formatting pass** for notes (the route is not `type`; rules chain, dictionary and snippets
   do run).
6. **Privacy refusal is loud, not silent**: nothing stored, nothing typed, `Notice::Error` says why.
7. **Files outside S35's own area touched**: `dictate-proto` (additive: `Route::Note`, `Note`,
   two commands, `CommandResult::Notes`, goldens), `dictate-core/{pipeline,ports,notify,router}.rs`
   (a dispatch arm + `note()` + `route_to_proto` + one `Notice` variant; **not** `engine.rs`),
   `dictated/src/server.rs` (two match arms: expect a textual conflict with S33 in `dispatch`),
   `ui/src-tauri/src/{app,commands}.rs`. `dictate-inject` untouched.
8. Search is ASCII case-insensitive only (SQLite `LIKE`).
