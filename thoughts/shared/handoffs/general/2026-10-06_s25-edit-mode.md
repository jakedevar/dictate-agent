## Design

- The router accepts spoken `edit` and existing colon prefixes. Trusted local
  protocol clients may force the existing EDIT route with an instruction only.
  Other ordinary verbs still route to Type. No wire-type changes.
- Explicit stop snapshots the actual focused X11 widget in the engine before
  waking recognition, alongside S23's profile snapshot. The first snapshot
  wins, including an unavailable destination. VAD stops snapshot in the
  pipeline. Uploads and callers lacking injection/context authority cannot
  read or replace a host selection.
- Only after routing to EDIT does the injector read PRIMARY and perform a
  clipboard-preserving Ctrl+C confirmation. A new clipboard owner from the
  destination's X11 client must appear; stale clipboard data cannot become an
  edit target. A conflicting PRIMARY owned by that client is rejected; an
  unrelated client's PRIMARY is ignored. Ctrl+C fallback works without PRIMARY.
- EditExecutor reuses S21's HttpBackend, ModelResolver, TimeoutPolicy and
  protected-span helpers. The selection and instruction are separate JSON
  data fields. The model must return a complete replacement with no commentary
  and valid protected spans; errors return no replacement. Limits: selection
  64 KiB, instruction 8 KiB, output 64 KiB.
- Before replacement the injector re-copies the selection and checks its bytes
  and focus. It pastes once, supplies text only to the destination's X11 client
  while that window is focused, and restores the clipboard using S13b Snapshot.
  It never raises a window, selects all, deletes, retries or types a fallback.
- Selection/LLM work races cancellation. Replacement owns the existing commit
  guard: cancellation that wins before it types nothing, and a later cancel
  returns TooLate/Conflict while the transaction completes.
- `[edit].preview_only` defaults false; true produces a proposal notification
  without replacing text. Session privacy and global history privacy suppress
  preview notifications and persisted interactions. The original selection is
  never stored by EDIT. EDIT errors use a separate notifier that does not
  overwrite the clipboard, unlike the legacy error notifier.
- `fmt_llm` measures edit inference and failures; `inject` measures replacement
  or reports the skip. Total wall time includes selection work. Forced EDIT is
  recorded as EDIT in interaction history.

## Deviations and limits

1. Use S21's client/resolver/timeouts, per the integrated base and Issue brief,
   rather than the old LocalExecutor generation/autospawn path. The model
   preference/ladder and host come from `[local]`; keep_alive and timeout come
   from `[format.llm]`. EDIT runs independently of prose formatter enablement.
   Explicit rewrites need their own validator: S21's prose drift thresholds
   would reject intended structural edits. Protected-span verification is reused.
2. Every PRIMARY capture is confirmed with fresh Ctrl+C, rather than trusting
   PRIMARY alone. PRIMARY can represent another or stale widget. This narrows
   backend support to conventional copy/paste apps using one X11 client.
3. Terminal profiles and all non-paste global/profile injection policies are
   refused. Ctrl+C can interrupt a terminal, and direct typing cannot provide
   failure-atomic replacement. Wayland and uploads are unsupported for EDIT.
4. Reuse the prefix and existing protocol forced-route surface; no additional
   dedicated hotkey or CLI flag was added. The prefix fulfills that entry path.
5. X11 does not expose an editable widget's actual selection range. Clipboard
   fallback cannot distinguish a selection from apps configured to copy a whole
   line without selection; that behavior must be disabled for EDIT. Identical
   selections within a widget and internal selection changes during a paste
   handshake cannot be distinguished portably. These limits are documented in
   `docs/edit-mode.md`; the automated guarantees cover conventional widgets.
6. Clipboard restoration retains S13b's existing format limits (text, HTML with
   text, image pixels). If delivery succeeds but restoration fails, log it and
   report delivery instead of retrying or claiming unchanged selected text.
7. Manual real-app checks are listed in `docs/edit-mode.md` for the operator or
   integrator. No live desktop test or GPU/Ollama performance claim is made.
   Only private Xvfb displays were used for X11 verification.

## Ownership / integration

No changes to `dictate-dict`, S20 rules, dictionary stages or snippet files.
Outside the named router/injector/pipeline regions, narrow changes add:
`edit_executor.rs` and its module export; `[edit]` aggregate/example config;
TextInjector's additive default selection methods and mocks; edit notifications;
engine/session's stop-window latch; and Pipeline.editor initializers in the
production daemon, test harness, dictionary example, real-E2E target and hotkey
unit fixture. The formatter integration regression now expects an EDIT with no
selection to fail closed instead of the old unimplemented-route skip, while
preserving the assertion that the prose formatter never runs.

The stop latch needs the engine/session changes together. The initializer
changes are wiring only. No new dependency or protocol golden update is needed.
