`dictate-parakeet` executable, pinned to FluidAudio

The macOS-only Rust provider owns one resident helper and a serialized worker
with one queued request. Frames have a u32 little-endian body length, a u32 JSON
header length, `{id,sample_rate:16000}`, and f32le mono PCM. Header is at most
4096 bytes, PCM at most ten minutes, response at most 64 KiB; nonfinite samples,
wrong IDs, malformed/oversized lines and non-English requests are refused.
`SttProvider::ready` gates the daemon's ready log; the existing API can show
`loaded=false` during preload. Startup is bounded to 120 seconds. A request's
processing/restart budget is `3 * audio_seconds + 5`; a failed request is not
replayed. Crash/timeout/protocol failure kills the child, marks it unloaded, and
the next request makes one restart attempt with exponential backoff capped at
five seconds. This lazy recovery is deliberate: idle failures do not create an
unbounded restart loop. A cancelled caller drops its result, queued cancelled
work is skipped, and an in-flight healthy response is drained so framing remains
synchronized. Shutdown aborts the worker and kills its child.

`[stt] provider = "parakeet" | "whisper"` selects the engine; existing configs
retain Whisper, new standard Mac installs explicitly select Parakeet with
`language = "en"`. Unsupported languages are errors. Product choice: English v2
is the Mac default; multilingual use explicitly selects the retained Whisper
large-v3-turbo/Metal fallback. There is no silent engine switch. Parakeet ignores
Whisper's vocabulary-bias prompt; the existing Rust dictionary/snippet stages
still apply. Diagnostics report verified Core ML model health. The Rust VAD,
text chain, routing, private HTTP UDS API, S33 peer ceiling and Linux default
provider remain the shared implementation.

# If [stt] already exists, set its provider="parakeet", language="en".
