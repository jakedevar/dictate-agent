# S13 injection v2 plan and decisions

## Scope

Replace the legacy one-shot clipboard helper with an async injection boundary
that can represent a consent-gated Wayland request, while shipping hardened
X11 behavior now. `dictate/` and `scripts/` remain untouched.

## Decisions

1. `dictate-inject::Injector::inject` returns a future and the core
   `TextInjector` port is async too. The existing protocol's
   `InjectionOutcome::AwaitingConsent` remains the distinct pending outcome;
   no protocol change is needed.
2. `InjectionPolicy` is `paste|type|off`. S23 can later select it from an app
   profile; S13 only supplies the policy value and capability resolver, not
   active-window discovery or profile matching.
3. Paste is selected only when the backend says clipboard save/restore is
   safe. Otherwise a requested paste resolves to direct type. A runtime paste
   failure retries direct type; if no delivery succeeds, the transcript is
   copied to clipboard best-effort and reported as an injection failure so the
   existing desktop notifier surfaces it.
4. The X11 transaction saves text before replacing it, restores after both
   success and failure, and always releases Ctrl after a failed paste key click.
   Direct typing is Unicode-safe chunked (default 512 scalar values).
5. Wayland probing is deliberately a seam only: its future tool order is
   `wtype → kwtype → dotool → ydotool`, and KDE/Plasma excludes `wtype`.

## Verification plan

- Unit tests: policy fallback, Unicode chunking, KDE `wtype` gate.
- Integration smoke: Xvfb launches xterm, focuses it with xdotool, injects a
  real paste, and reads the text back from xterm.
- Workspace tests and clippy use the required CUDA PATH and
  `WHISPER_DONT_GENERATE_BINDINGS=1` environment.

## Risks

- The current X11 clipboard API preserves textual clipboard contents. Arbitrary
  binary clipboard targets are outside arboard's portable snapshot interface.
- Wayland portal injection is not implemented; its async/consent and policy
  contracts are in place for the R3 backend implementation.
