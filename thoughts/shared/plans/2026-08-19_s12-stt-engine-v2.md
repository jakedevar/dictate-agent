# S12 — STT Engine v2

## Scope and decisions

1. Move the final object-safe `SttProvider` contract, request options, model
   status, and per-call timings into `dictate-stt`; `dictate-core` will consume
   and re-export that public API rather than own a temporary seam.
2. Keep one serialized whisper-rs worker because `WhisperState` is not safely
   shareable. The worker selects the actual backend at context load, preserves
   the 23 legacy corrections, supports configured or request-level language and
   vocabulary prompt overrides, and returns honest load/decode/total timings.
3. Add a static, single-family GGUF catalog. It pins Hugging Face revision
   `5359861c739e955e79d9a303bcbc70fb988958b1`, expected SHA-256, and byte
   count for `large-v3-turbo` and the CI `tiny.en` fallback. Pulls use a `.part`
   file, Range resume, SHA-256 verification, corrupt-file deletion, and one
   clean retry.
4. Add `dictate model pull [name]` and `dictate model list`, defaulting to
   `large-v3-turbo`; make the production provider ensure the configured catalog
   model is present before its first load. Explicit model paths remain supported
   for offline/custom GGUFs.
5. Add fixture-oriented tests for configuration, catalog, checksums, corrupt
   deletion, resume, retry, correction coverage, and CPU/tiny fallback shape.
   CUDA decode is separately benchmarked on the installed RTX 5080 and recorded
   with exact fixture and backend details.

## Verification plan

- `PATH=/opt/cuda/bin:$PATH WHISPER_DONT_GENERATE_BINDINGS=1 cargo test --workspace`
- `PATH=/opt/cuda/bin:$PATH WHISPER_DONT_GENERATE_BINDINGS=1 cargo clippy --all-targets --workspace -- -D warnings`
- Execute the CUDA benchmark against the pinned installed `large-v3-turbo`
  model and a reproducible 16-kHz speech WAV generated by `espeak-ng`; record
  raw samples, p50/p95, GPU/driver, model checksum, and the R2 recommendation.

## Outcome

Implemented and benchmarked. The recovery validation run measured warm CUDA
p50 113.262 ms and p95 114.314 ms for the documented 7.949 s fixture; cold
model load was 658.419 ms. The benchmark artifact preserves the prior initial
run too, because host contention can materially affect this measurement. It
recommends R2 **NO-GO** because an additional full partial decode has no
demonstrated contention-safe margin.

## Non-goals

- Live partials remain R2 work; this slice supplies the measured decision gate.
- Dictionary persistence and dynamic vocabulary assembly remain S22; S12 only
  exposes the request/config `initial_prompt` hook it will consume.
